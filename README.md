# 🧬 bio-info-science

Mon parcours d'apprentissage en génétique et en bio-informatique.

## Pourquoi

Je suis développeur, et je veux mettre mes compétences au service de la recherche sur le cancer. Ce dépôt documente mon apprentissage, étape par étape : les concepts, les exercices et les programmes que j'écris en chemin.

## Le plan

- [ ] **Phase 1 — Fondations** (mois 1 à 6) : biologie moléculaire, Python appliqué, problèmes Rosalind, traducteur ADN → protéine
- [ ] **Phase 2 — Outils et vraies données** (mois 7 à 12) : ligne de commande, formats génomiques (FASTA, FASTQ, VCF), bases de données publiques (NCBI, Ensembl)
- [ ] **Phase 3 — Génomique du cancer** (année 2) : des données de séquençage aux mutations, bases COSMIC et TCGA, projet portfolio

## Rythme

Deux sessions par semaine :

- **Mardi** : session concept (leçon et exercices)
- **Jeudi** : session code (programmation et commit)

## Structure

```
phase1-fondations/         Exercices et programmes de la phase 1
phase2-outils/             Outils et données réelles
phase3-genomique-cancer/   Projets en génomique du cancer
journal/                   Notes de fin de session
```

## Journal

Chaque session se termine par une note de 3 lignes dans [`journal/journal.md`](journal/journal.md) : ce que j'ai appris, où je me suis arrêté, et la prochaine étape.
